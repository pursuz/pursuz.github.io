# 项目：PURSUZ-KV

## 项目背景
- 基于 TCP 的内存型 KVStore：提供 SET/GET/DEL 等基础能力，支持多连接并发访问与命令解析响应。
- 项目覆盖从网络 I/O、协议处理到数据结构实现与压测验证的完整链路。

## 技术介绍
- 服务端通过 TCP 提供文本协议接口：请求为“空格分隔命令”，响应以 \r\n 结尾，便于用 telnet/netcat 或自写客户端快速调试。
- 网络层提供多种并发模型实现：epoll reactor、io_uring proactor、以及协程网络模型，可按编译期开关选择不同实现路径。
- 存储引擎提供多种数据结构实现：数组、哈希表、红黑树、跳表；命令前缀区分不同引擎（例如 SET/RSET/HSET），以便按场景选择与验证效果。
- 配套提供 testcase 进行功能验证与简单压测，并附带多语言客户端示例，便于快速联调与测试。

## 技术栈
- 语言：C
- 构建：Makefile
- 网络：epoll / io_uring / 协程（依赖 liburing 与 NtyCo）
- 数据结构：数组表、哈希表、红黑树
- 代码位置：`kvstore/kvstore`
