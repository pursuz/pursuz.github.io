# 项目：远程监控系统

## 项目背景
- Windows 远程监控演示系统：服务端可查看客户端屏幕截图，并对客户端下发退出/注销/重启/关机等控制命令。
- 覆盖远程监控的核心链路：连接管理、图像采集与传输、显示渲染、远程控制指令下发与执行。

## 技术介绍
- 系统分为服务端与客户端两套 MFC 程序，双方通过 TCP 长连接通信。客户端启动后读取 ini 配置连接服务端，服务端维护已连接客户端列表。
- 监控流程为“按需开始/停止”：服务端选择某客户端后下发开始监控命令，客户端开始抓屏并上传；服务端接收位图数据并在监控窗口中缩放绘制显示；关闭监控窗口时再下发停止监控命令。
- 图像传输采用简单的自定义二进制协议：先发送固定头（cmd/length），随后发送 BITMAP 结构体与原始位图像素数据，服务端按相同顺序接收并组装显示。
- 远程控制命令通过同一通道下发：服务端可下发退出/注销/重启/关机等指令，客户端收到后使用系统 API 执行对应操作。
- 工程要点在于把“网络收发”和“图像采集/渲染”拆开，形成清晰的端到端数据流，便于学习与扩展（例如补充鼠标键盘事件等）。

## 技术栈
- 语言：C++
- GUI：MFC 对话框
- 网络：MFC CSocket（TCP）
- 采集/绘制：GDI（抓屏与位图绘制）
- 构建：Visual Studio/MSBuild
- 代码位置：`远程监控系统`
