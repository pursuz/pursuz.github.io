# 项目：DesktopPet

## 项目背景
- Windows 桌宠与桌面工具集合：包含桌宠窗口（动图/视频）、桌宠管理器、壁纸管理、桌面快捷方式分组透明框等功能。
- 面向桌面个性化与效率工具场景，提供可扩展的桌宠资源与行为配置体系。

## 技术介绍
- 桌宠以“资源 + 配置”驱动：每个桌宠目录包含 pet.json 与素材资源，管理器负责扫描 pets/ 目录并将新增/删除的桌宠热加载进列表。
- 桌宠的交互采用“事件→动作”模式：startup/click 等事件触发 play/nudge/say 等动作，行为可在 UI 中编辑后保存回 pet.json，使桌宠无需改代码即可调整交互逻辑。
- 动画渲染支持多种资源形态：帧序列（按 fps 播放）、GIF（QMovie）、MP4（QMediaPlayer）。MP4 通过视频帧抓取并绘制成 QImage，兼容 Qt5/Qt6 的不同多媒体接口。
- 窗口行为做了桌宠常见特性：无边框、置顶、透明背景；并通过 Win32 扩展样式实现鼠标穿透开关，适配“桌面装饰/不影响操作”的使用场景。
- 除桌宠外还包含桌面工具：壁纸管理（设置/恢复系统壁纸）与快捷方式分组透明框（扫描桌面快捷方式、双击启动、可拖动与持久化）。

## 技术栈
- 语言：C++17
- UI：Qt Widgets（兼容 Qt5/Qt6）
- 多媒体：Qt Multimedia
- 平台：Windows API（壁纸、ShellExecute、窗口样式/穿透）
- 构建：CMake
- 代码位置：`DesktopPet`
