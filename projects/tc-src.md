# 项目：tc-src

## 项目背景
- 图床/网盘类后端服务：提供用户注册/登录、文件上传与分享等能力，支持把文件存入分布式存储并通过 HTTP 访问。
- 项目重点在“工程化上传链路”：把大文件接收与落盘交给 Nginx，后端只做业务处理与入库，从而降低后端对大流量上传的压力。

## 技术介绍
- 整体架构由网关与后端服务组成：Nginx 负责静态资源与反向代理，并承担“大文件上传接入”——先把文件体落盘，再把文件信息以表单字段转发给后端接口。
- 后端服务（C++）负责业务与数据一致性：解析 Nginx 转发的文件信息（路径、大小、MD5、类型等），完成入库、秒传判断、分享关系维护、列表查询等接口逻辑。
- 存储层对接采用“对象存储/分布式文件系统”思路：文件落在 FastDFS 集群，MySQL 保存用户与文件元数据，Redis 负责 token、计数与排行榜等热点数据，形成典型的“冷热分离”。
- 接口按业务拆分为多个模块：注册/登录/上传/分享/列表等在 api/ 目录下拆分实现，http_conn 负责路由分发与请求处理，base 提供网络/线程池/配置等基础设施。
- 可选能力包含短链服务：通过 gRPC/Protocol Buffers 把长 URL 映射成短链，配合 Nginx 路由实现分享链接简化。
- 对外展示不包含任何密钥、token、账号等敏感字段；文档仅描述架构与流程。

## 技术栈
- 语言：C++
- 构建：CMake
- 网关：Nginx（反向代理/上传接入）
- 数据库：MySQL（连接池）
- 缓存：Redis（连接池）
- 序列化：jsoncpp
- 日志：spdlog
- 文件存储：FastDFS（对接）
- 可选：gRPC/Protocol Buffers（短链）
- 代码位置：`tc-src`
