# 项目：shellcode加壳

## 项目背景
- Windows 系统编程与逆向学习示例：通过最小可运行样例理解 shellcode 的自举执行、导出表解析与 API 动态解析思路。
- 合规声明：仅用于安全研究与演示，请在获得授权的隔离环境中测试；禁止用于未授权入侵或规避安全防护。

## 技术介绍
- 该目录包含多个子项目，分别展示不同的 API 解析与调用组织方式：
- shellCode：通过 PEB/LDR 链表定位模块基址，解析导出表并用哈希匹配函数名，从而获得 API 地址后调用（示例以弹窗与退出为主）。
- shellcode2：在运行时构造所需字符串，遍历导出表并用字符串比较定位目标函数，强调“导出表遍历 + 明文匹配”的直观实现。
- shellcode加解密：以哈希值替代明文 API 名进行匹配，减少静态特征，展示“哈希匹配”在解析链路中的使用方式。
- 整体关注点在底层机制：PEB/TEB 访问、导出表（EAT/ENT/EOT）解析、以及在无显式导入表依赖下组织调用链。工程实现偏学习版自举，并非完整的通用 PE loader 或对抗型壳方案。
