# 项目：WhaleDeviceServer

## 项目背景
- 面向相机/投影仪等硬件的设备服务进程：把多厂商设备控制、触发与数据采集封装成统一服务，向上层应用提供稳定的“取图/取点云/参数读写”接口。
- 适用于 3D 采集链路：统一协调多相机采集、投影仪投图/触发、点云/高度图合成与输出，降低上层业务与硬件 SDK 的耦合。

## 技术介绍
- 整体设计采用“服务化 + IPC + 多线程流水线”：设备服务作为独立进程运行，内部启动多路采集与处理线程；上层应用通过 DLL 接口发起请求，底层通过共享内存与信号量/事件进行进程间通信与大数据传输。
- 服务端将采集链路拆成多个阶段：相机采集（多路并行）、数据转换/整理、最终点云/高度图合成与输出。这样可以把设备 I/O 与计算解耦，并通过队列与线程隔离波动。
- 触发模式支持软触发与硬触发：由配置决定触发策略，兼容不同硬件与生产线节拍；同时保留部分旧接口模式以便迁移。
- 点云/高度图由外部合成库完成：服务负责组织多路数据与参数，将合成结果回填到共享内存数据区，供上层一次性读取。
- 工程同时包含示例与测试：提供调用 DLL 的示例程序，以及并发请求/取最终点云的测试用例，便于验证稳定性与吞吐。
- 跨平台运行形态：Windows 以 Service 安装运行；Linux 以 systemd 方式安装与管理。

## 技术栈
- 语言：C++20
- 构建：CMake（多子模块）
- 图像/矩阵：OpenCV
- 配置：XML（pugixml 等）
- IPC：共享内存 + 信号量/事件
- 硬件：多厂商相机/投影仪 SDK（适配层 + 工厂/抽象）
- 部署：Windows Service / Linux systemd；Windows 安装包使用 Inno Setup
- 代码位置：`WhaleDeviceServer`
