# 项目：AOISDK-演示程序

## 项目背景
- AOISDK 的桌面演示程序：用于把 SDK 的调用流程、输入参数组织方式与输出结果展示做成可视化可复现的样例。
- 面向“算法/SDK 使用者”和“数据回归”场景：同一套参数可重复跑，方便定位问题与对比效果。

## 技术介绍
- 演示程序把 AOI 检测拆成可操作的流程：加载 2D 原图与对应点云（TIFF 深度）、框选待检 ROI、选择模板图、填写器件参数与焊点/针脚信息，最后调用 SDK 的 Detect* 接口并展示结果。
- 输入组织方式更贴近真实业务：除了 ROI 的中心点/尺寸/角度外，还支持把器件参数（例如文字/色环数量/排针行列等）与焊点信息（列表）统一打包，形成“一键复现”的 JSON 参数集。
- 结果展示覆盖业务关心项：缺陷类型、角度偏差、异常针脚索引；并把 SDK 返回的异常区域 mask 渲染成结果图，便于直观看到“哪里被判为异常”。
- 同时提供点云量测能力的示例入口：ROI 最大高度/体积提取、去地面图生成等，用于演示 2D+3D 融合时 3D 指标如何参与判定与调试。
- UI 结构为三列：左侧原图交互与模板选择，中间预览与结果图，右侧器件类型与参数面板以及日志输出；该界面组织方式可直接迁移到 SDK 集成类工具中复用。

## 技术栈
- 语言：C++17
- UI：Qt Widgets
- 依赖：OpenCV、PCL（含 VTK）、AOISDK 动态库
- 构建：CMake（AUTOUIC/AUTOMOC/AUTORCC）
- 代码位置：`AOISDK-演示程序`
