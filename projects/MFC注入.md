# 项目：MFC注入

## 项目背景
- MFC MDI（多文档）应用骨架工程：包含菜单/工具栏/状态栏与可停靠面板（文件视图/类视图/输出/属性），可作为桌面工具类应用的 UI 框架基础。
- 说明：当前仓库代码未包含典型“进程注入”实现，更接近一个 VS 风格 MDI 工程模板/框架外壳。

## 技术介绍
- 工程重点在 MFC 框架结构：应用入口初始化文档模板与主框架窗口；主框架负责创建菜单、工具栏、状态栏，并启用 MDI 标签页管理。
- UI 组织采用可停靠窗格：FileView/ClassView/Output/Properties 等面板作为独立窗格创建并注册到 Docking 系统，形成类似 IDE 的多面板布局能力。
- 输出窗口提供多 Tab（Build/Debug/Find）与右键操作示例，便于后续替换为日志、编译信息或自定义输出。
- 框架预留了 Doc/View 与自定义窗格的扩展点，便于后续接入业务模块与工具窗口。

## 技术栈
- 语言：C++（Unicode）
- GUI：MFC（MDI + Docking Pane）
- 构建：Visual Studio/MSBuild
- 代码位置：`MFC注入`
