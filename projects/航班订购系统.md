# 项目：航班订购系统

## 项目背景
- 航班查询与预订演示系统：包含客户端与服务端两套桌面程序，覆盖航班管理、查询、订票/退票/改期与订单查看等核心业务。
- 采用“桌面 UI + TCP 通信 + MySQL 持久化”的端到端实现方式，体现客户端/服务端分工与库存/订单一致性处理。

## 技术介绍
- 系统分为 Client 与 Server：服务端负责监听连接并处理登录/注册、订票/退票/改期等涉及库存与订单变更的写操作，同时提供航班信息的后台管理界面（新增/修改/删除）。
- 客户端提供用户交互：登录/注册后可按航班号、日期、出发地/目的地、价格区间等组合条件查询航班列表，并发起订票/退票/改期操作与查看“我的订单”。
- 订票链路强调一致性：服务端收到订票请求后会校验余票、扣减库存并写入用户购票记录；退票则删除记录并回补库存；改期则在更新订单的同时对新旧航班的库存做同步调整。
- 航班管理包含舱位票价的业务规则：服务端维护不同舱位（头等/商务/经济）票价，支持通过倍率联动计算并保存，体现典型的“配置规则 + 数据落库”场景。
- 通信采用简化文本协议：基于 TCP 连接传输 Unicode 逗号分隔的命令串，首段为命令号，便于联调与快速定位问题。
- 数据库以 MySQL 为中心：航班表、舱位票价表、用户表、用户购票记录表等构成业务闭环，客户端展示与服务端更新均围绕这些表完成。

## 技术栈
- 语言：C++（Unicode）
- GUI：MFC（客户端/服务端）
- 网络：MFC CSocket（TCP）
- 数据库：MySQL C API
- 构建：Visual Studio/MSBuild
- 代码位置：`航班订购系统`
