# 项目：Qt飞机大战

## 项目背景
- 基于 Qt Widgets 开发的竖版飞行射击小游戏，实现从输入控制到渲染刷新、碰撞判定与动画反馈的完整闭环。
- 项目包含玩家/敌机/子弹/地图/动画等模块，体现典型 2D 游戏的基础结构组织方式。

## 技术介绍
- 游戏采用定时器驱动的帧循环：固定帧率下更新游戏对象状态，并触发重绘完成显示刷新。
- 对象以实体系统组织：玩家/敌机/子弹/爆炸动画都实现统一的 update/draw 接口，集中由管理器维护与回收，从而避免逻辑分散在 UI 代码中。
- 碰撞检测使用包围盒相交：每帧更新精灵的 QRect 碰撞盒，检测子弹-敌机、玩家-敌机的相交关系，并触发相应的爆炸动画与对象销毁。
- 动画以帧序列方式实现：按时间推进切换帧图，爆炸动画播放结束后自动销毁，形成清晰的“事件→效果→回收”闭环。
- 资源使用 Qt 的 qrc 内嵌：图片通过资源路径加载，减少运行时路径依赖，便于分发与展示。
