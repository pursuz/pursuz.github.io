# 项目：DPDK

## 项目背景
- 基于 DPDK 的用户态网络实践整理：覆盖从报文收发、基础协议处理到协议栈架构的原型验证与设计沉淀。
- 内容包含文档与原型实现，用于展示对数据面收发包与协议处理链路的理解与工程化拆解能力。

## 技术介绍
- 内容分为三层：
- 第一层是 DPDK 基础与运行要点：巨页、端口/队列初始化、性能相关概念（如 CPU 亲和、批量收发等）的整理，帮助快速搭建可运行环境。
- 第二层是协议处理的实战拆解：以 ARP 与 ICMP 为切入点，展示如何解析以太网帧、构造 ARP/ICMP 报文并回发；ARP 部分还包含 ARP 表维护与定时广播扫描等工程要点。
- 第三层是用户态协议栈设计草案：围绕多线程模型与 ring buffer 解耦收包线程与协议处理线程，讨论 offload 数据结构组织方式，并给出类 socket 的 UDP API 设计方向（bind/recvfrom/sendto/close 等），体现从“能收发”到“可复用接口”的演进思路。

## 技术栈
- 方向：DPDK（用户态网络）
- 协议：Ethernet / ARP / IPv4 / UDP / ICMP
- 形式：学习文档 + 原型代码/伪代码
- 代码位置：`DPDK`
