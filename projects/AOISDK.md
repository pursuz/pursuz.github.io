# 项目：AOISDK

## 项目背景
- 面向 AOI（自动光学检测）的 C++ SDK：给上层检测软件提供统一接口，输入 2D 图像与 3D 点云，输出器件缺陷与量测结果。
- 典型用于 PCB 器件检测：缺件/错件/损坏/方向偏差、针脚/焊点异常等，并能结合 3D 信息辅助判断翘脚、少锡等问题。

## 技术介绍
- 整体思路是“2D 外观 + 3D 形貌”协同：2D 用于定位与纹理差异，3D 用于高度/体积等几何量测与去地面基准构建。
- 2D 能力侧重在可复用的基础算子上：旋转模板匹配用于器件定位与角度估计；结构相似度/匹配因子用于筛出异常区域；形状匹配用于轮廓/区域级的相似性定位（可做角度范围旋转匹配）。
- 文字相关场景提供 OCR 能力：以 ONNX 推理形式组织文本检测、方向分类与文本识别，可用于丝印/字符一致性校验（例如“错件/混料”的辅助特征）。
- 3D 能力围绕“平面基准 + ROI 量测”：通过 RANSAC 平面拟合/分割得到 PCB 底面并生成 mask；在此基础上对多个 ROI 批量计算最大高度与体积等指标，同时可导出去地面后的结果图用于调试与可视化。
- 业务接口以器件/封装类型组织：提供多组 Detect* 检测入口（如贴片电阻/电容、矩形芯片含针脚/文字、排针、按键、晶振、电感、LED、钽电容、晶圆切割等），统一输出缺陷类型、角度偏差、异常针脚索引、异常区域 mask 与调试图。
- 代码按模块拆分：core（日志/配置/通用工具）、image（2D 算子与 OCR）、poindcloud（3D 分割与量测）、pcbanalysis（各器件检测策略）。

## 技术栈
- 语言：C++（工程配置为 C++20）
- 构建：CMake（多子模块）
- 图像：OpenCV 4.x
- 点云：PCL 1.12.x
- 推理：ONNX Runtime（OCR 模型）
- 文档：Doxygen
- 代码位置：`AOISDK/2-AOISDK`
