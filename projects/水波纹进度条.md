# 项目：水波纹进度条

## 项目背景
- Qt 自定义控件：圆形水波纹进度条，用更具动效的方式展示进度/占比，常用于下载、加载、仪表盘等场景。
- 控件实现覆盖自绘、路径裁剪、动画刷新与参数绑定等典型 UI 技术点。

## 技术介绍
- 控件以圆形为容器，内部用正弦波模拟水面：进度值映射为水位高度，波形随时间推进产生流动效果。
- 绘制采用 QPainterPath：先构造“波面+底部封闭区域”的路径，再与圆形路径求交得到圆内裁剪效果，从而避免额外的裁剪状态管理。
- 动画通过相位推进实现：定时器周期更新波形相位，配合 setValue/update 实现平滑刷新；示例窗口用 QTimer 驱动进度变化，直观展示效果。
- 控件支持基本参数：最小/最大值、当前值，尺寸变化时自动自适应，中心显示百分比文本，便于直接嵌入到实际项目 UI 中使用。

## 技术栈
- 语言：C++17
- UI：Qt Widgets（QPainter/QPainterPath）
- 构建：CMake（兼容 Qt5/Qt6）
- 代码位置：`水波纹进度条/SWaterProgressBar`
