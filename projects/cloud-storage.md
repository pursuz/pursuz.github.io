# 分布式云文件存储系统

## 项目概述

基于 C++11 开发的高性能云图床后端服务，采用 Reactor 网络模型，支持高并发文件上传、下载、分享、短链访问。面向个人开发者和小型团队，提供稳定可靠的文件托管服务。

## 架构设计

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   Client    │────▶│  Nginx (LB)      │────▶│  C++ Backend    │
└─────────────┘     └──────────────────┘     └────────┬────────┘
                                                       │
                              ┌─────────────────────────┼─────────────────────────┐
                              │                         │                         │
                              ▼                         ▼                         ▼
                    ┌──────────────┐          ┌──────────────┐          ┌──────────────┐
                    │  FastDFS     │          │  MySQL       │          │  Redis       │
                    │  (文件存储)   │          │  (业务数据)   │          │  (热数据缓存) │
                    └──────────────┘          └──────────────┘          └──────────────┘
```

### 三层架构

- **接入层**：Nginx 负载均衡，反向代理，HTTPS 终结
- **业务层**：C++ 后端服务，基于 Muduo 网络库实现 Reactor 模型
- **存储层**：FastDFS 集群存储文件，MySQL 集群存储元数据，Redis 集群缓存热点数据

## 核心功能

### 文件管理
- 多格式文件上传（图片、视频、文档）
- 分片上传，支持断点续传
- 文件秒传（MD5 去重）
- 文件版本管理

### 分享与访问
- 生成分享链接，支持有效期设置
- 短链访问，自动跳转
- 访问密码保护
- 访问统计与日志

### 性能优化
- Reactor 网络模型，单机支持万级并发连接
- Redis 缓存热点文件元数据，减少数据库压力
- 异步日志系统，避免 I/O 阻塞
- 内存池减少频繁分配开销

## 技术栈

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 网络模型 | Muduo (Reactor) | 高性能事件驱动 |
| 文件存储 | FastDFS | 分布式文件系统 |
| 数据库 | MySQL | 业务元数据存储 |
| 缓存 | Redis | 热数据缓存、会话管理 |
| 负载均衡 | Nginx | 反向代理、负载均衡 |
| 构建工具 | CMake | 项目构建管理 |
